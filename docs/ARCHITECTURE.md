# هيكلية وهندسة مشروع "خزنة الذهب" (Gold Vault Tracker Architecture)

## 1. نظرة عامة والمعايير الهندسية
تطبيق أندرويد متكامل مبني بالكامل بأحدث معايير **Jetpack Compose** و**Material Design 3** بنمط **Clean Architecture / MVVM**.
صُمم التطبيق لإدارة ومتابعة محافظ الذهب الحقيقية (السبائك والمشغولات) بالسوق المصري والعالمي، مع حساب دقيق لقيم التصفية الحقيقية (سعر شراء الصائغ للكسر وليس سعر بيع المحل)، وحسابات الكاش باك القياسي (28 ج.م/جم)، وتتبع الأرباح بدقة مالية متناهية تمنع أي خطأ تقريب أو قسمة على صفر.

## 3. طبقات البناء المعماري (Architectural Layers)

### أ. طبقة النطاق والحسابات (Domain & Math Engine)
- **`PortfolioCalculator.kt`**:
  - الحساب الدقيق باستخدام `BigDecimal` لمنع أي أخطاء نقطة عائمة في الأموال.
  - التفريق الصارم بين **سعر شراء الصائغ (Jeweler Buy Price)** و**سعر بيع المحل (Retail Sell Price)**.
  - حساب كاش باك السبائك المعياري بمعدل 28 ج.م / جرام (`STANDARD_BULLION_CASH_BACK_PER_GRAM = 28.0`).
  - **منع ازدواجية الكاش باك**: احتساب الكاش باك كبند محفظي مستقل يضاف مرة واحدة فقط إلى إجمالي قيمة التصفية (`calculateTotalLiquidation`).
  - حماية كاملة ضد القسمة على صفر أو القيم السالبة والمدخلات التالفة (`NaN` / `Infinite`).

### ب. طبقة البيانات والمرونة الشبكية (Data & Resilient Remote Layer)
- **استراتيجية تعدد مصادر الأسعار (Multi-Tier Resilient Price Sourcing)**:
  1. **المستوى الأول**: استدعاء `Retrofit` المباشر لـ `GoldAPI.io` لأسعار الذهب العالمية والفورية.
  2. **المستوى الثاني**: جلب فوري ومباشر لسعر أونصة الذهب العالمية (XAU/USD) عبر فاحص موقع `Investing.com` من الرابط المعتمد:
     `https://sa.investing.com/currencies/xau-usd`.
  3. **المستوى الثالث**: استخراج أسعار الصاغة المصرية الحقيقية محلياً (شراء وبيع عيار 24، 21، 18) عبر مكشطة `iSagha`.
  4. **المستوى الرابع (وضع الأمان)**: في حال انقطاع الشبكة، يتحول التطبيق تلقائياً إلى وضع **الإدخال اليدوي المباشر (Manual Mode)** مع الاحتفاظ بالقيم الآمنة دون أي تصفير أو انهيار.

### ج. طبقة التخزين المحلي والتهيئة الذاتية (Room Database & Self-Seeding)
- **الإصدار 3 مع الترحيل التدميري الآمن**:
  - معالجة أحداث دورة الحياة `onCreate` و`onDestructiveMigration` و`onOpen`.
  - ميزة **التهيئة الذاتية الفورية (`ensureInitialDataSeeded`)**: في حال خلو قاعدة البيانات عند أول إقلاع أو بعد تحديث المخطط، يتم تلقائياً شحن:
    - 5 سبائك BTC أصلية بوزن **92.6035 جم** وتكلفة **673,000 ج.م**.
    - مشغولات ذهب مصري عيار 21 بوزن **64.900 جم**.
    - رصيد مرجعي ابتدائي: **1,000,462 ج.م** وهدف مالي **1,250,000 ج.م**.

### د. طبقة واجهة المستخدم (Jetpack Compose UI)
- **دعم كامل للشاشات الحديثة ونظام Android 15**:
  - تفعيل `enableEdgeToEdge()` وتضمين هوامش الأمان `WindowInsets.safeDrawing`.
  - واجهة عربية أصيلة باتجاه **RTL** كامل (`LayoutDirection.Rtl`).
  - ميزة **السحب لأسفل للتحديث (Pull-to-Refresh)** عبر `PullToRefreshBox` من Material 3.
  - رسم بياني حي Canvas بأقواس Bézier وتدرج ذهبي وانعكاسات ناعمة مع مؤشر لمس تفاعلي (Touch Scrubber Tooltip) وفلاتر الفترات: يومي (1D)، أسبوعي (1W)، شهري (1M)، 3 شهور (3M).
  - تنبيهات قابلة للتخصيص لتحركات الأسعار بهوامش ديناميكية (10، 25، 50، 100 ج.م).
