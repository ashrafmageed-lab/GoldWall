# 🌟 خزانة الذهب (Gold Vault Tracker)

تطبيق أندرويد متقدم ومتكامل لإدارة وتتبع محافظ الذهب الحقيقية (السبائك والمشغولات) بالسوق المصري والعالمي، مبني باستخدام **Kotlin** و**Jetpack Compose** بأحدث تقنيات Material Design 3 ومعمارية **Clean Architecture / MVVM**.

---

## 📌 الميزات الرئيسية للتطبيق (Key Features)

1. **حساب التصفية والتسييل الحقيقي (Jeweler Liquidation Value)**:
   - التقييم العادل والمباشر بناءً على سعر شراء الصائغ الفعلي للذهب الكسر، دون خلطه بأسعار بيع المحلات للمستهلك والمصنعية.

2. **كاش باك السبائك المعتمد (28 جنيه / جرام)**:
   - احتساب الكاش باك لسبائك BTC الأصلية المغلفة والسليمة بمعدل 28 ج.م لكل جرام، وإضافته تلقائياً للتصفية دون أي ازدواجية في الحساب مع دعم التحكم في احتسابه من الإعدادات.

3. **لوحة بيانية تفاعلية متقدمة لتوزيع المحفظة (D3 / Recharts-inspired Donut Dashboard)**:
   - مخطط حلقي تفاعلي (Interactive Donut Chart) مرسوم بـ Compose Canvas عالي الأداء مع حركة انسيابية.
   - **توزيع حسب العيار**: عيار 24 (سبائك نقي 999.9)، عيار 21 (نقاء 875)، عيار 18 (حلي فاخرة).
   - **توزيع حسب نوع الأصل**: السبائك الاستثمارية مقابل المشغولات الذهبية.
   - **توزيع حسب القيمة السوقية**: تسييل السبائك، تسييل المشغولات، وعوائد الكاش باك.
   - بطاقة فحص تفاعلية عند لمس أي شريحة لحساب الذهب الصافي عيار 24 المكافئ ونسبة نقاء المحفظة الإجمالية.

4. **تنبيهات الأسعار التلقائية في الخلفية (WorkManager Price Alerts)**:
   - فحص دوري مستمر في الخلفية كل 15 دقيقة عبر **AndroidX WorkManager**.
   - تنبيهات هوامش التحرك السعري (Delta Threshold: 10، 25، 50، 100 ج.م).
   - تنبيهات الأسعار المستهدفة: **السقف الصعودي (Target Ceiling)** لجني الأرباح و**القاع الهبوطي (Target Floor)** للتعزيز والشراء.
   - قناة إشعارات عالية الأهمية (`IMPORTANCE_HIGH`) مع دعم التنبيه التجريبي الفوري.

5. **تفضيلات العملة ووحدات الوزن (Multi-Currency & Multi-Weight)**:
   - إمكانية التبديل بين الجنيه المصري (**EGP**) والدولار الأمريكي (**USD**).
   - إمكانية التبديل بين الجرام (**Gram**) والأونصة التروي الدولية (**Troy Ounce = 31.1035g**).

6. **أمان وقفل الخزانة (Security & Biometrics)**:
   - قفل التطبيق برمز PIN مشفر بخوارزمية **PBKDF2** ضد هجمات القوة الغاشمة.
   - دعم المصادقة البيومترية ببصمة الإصبع (**BiometricPrompt**).
   - إمكانية اشتراط الرمز السري عند بيع أو تسييل أي أصل.

7. **رسم بياني حي لتاريخ التقييم (Interactive Valuation Chart)**:
   - رسم بياني بأقواس Bézier ناعمة مع مؤشر لمس تفاعلي (Touch Scrubber Tooltip).
   - فلاتر الفترات الزمنية: يومي (1D)، أسبوعي (1W)، شهري (1M)، 3 شهور (3M).

8. **قاعدة بيانات محلية آمنة (Room Database v8)**:
   - تشفير وحفظ كامل على ذاكرة الجهاز بدون خوادم خارجية لضمان الخصوصية التامة.
   - نسخ احتياطي بتنسيقات JSON و CSV.
